        RESUME SUR LES PRINCIPES SOLIDES

  avec les peincipes solides , on rend le code plus propre et plus facil a etre extentier , fermer a la modification et ouverte a l'extention ( OCP ) . Et elle est indispensable car elle rend le code  plus claire et rend l'implementation plus facile .
  TOUT CE QUI CONCERNE CHAQUE PRINCIPES SOLIDES :

   - SRP ( SINGLE RESPONSABILITY PRINCIPLE ) : Une classe = une responsabilites .
   - OCP ( OPEN CLOSED PRINCIPLE ) : le code doit etre fermé a la modification et ouverte a l'extention .
   - LSP (LISKOV SUBTITUTION PRINCIPLE ) : toutes les sous classe peuvent etre subtitutuer sans causer de comportement anormal a la class parent .
   - ISP ( INTERFACE SEGREGATION PRINCIPLE ) : preferés les petites interfaces ciblés .
   - DIP ( DEPENDENCY INVERSION PRINCIPLE ) : les modules de haut niveau ne doivent pas dependre des modules de bas niveaux .
